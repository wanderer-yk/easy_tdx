## 一、帧头字段的实盘观察

### C2S 请求帧（10 字节头）

`codec/mac_frame.py` 的 `<BIBHH` 结构在实盘字节上逐位吻合：

| 偏移 | 类型 | easy_tdx 字段 | 终端实盘观察 |
|------|------|--------------|-------------|
| 0 | B | head_flag（构建时发 0x1C） | 观察到 **0x00**（行情类命令）——服务端同时接受两种值 |
| 1-4 | I | customize（构建时发 0） | **逐帧变化**（如 `1a002f12`→`04002b12`→`1c001814`），形似连接内序号/会话标识 |
| 5 | B | version | 恒为 0x01 ✓ |
| 6-7 | H | zipsize | ✓ = body 长度（含 2 字节 msg_id 前缀） |
| 8-9 | H | unzipsize | ✓ 恒等于 zipsize |
| 10-11 | H | msg_id | ✓（0x122B/0x122E/0x1215/0x1217/0x123D…） |

**运维含义**：customize 字段服务端不校验（easy_tdx 发 0 可用，终端发变化值也可用）；
head_flag 存在多个合法值（0x1C/0x00），未来若遇命令突然失效可先排查此字段。

### S2C 响应帧（16 字节头，`<IIIHH`）

| 偏移 | 实盘观察 |
|------|---------|
| 0-3 | **连接内恒定**（如 `b1cb7400`），疑似连接标识；跨连接是否复用未验证 |
| 4-5 | `0x0cNN`，NN 随响应递增——响应序号 |
| 6-7 | **回显请求帧偏移 2-3**（终端请求的 customize 尾字节），可做请求-响应关联 |
| 8-9 / 10-11 | 响应消息号（与请求 msg_id 一致，双写） |
| 12-13 / 14-15 | body 长度（双写） |

### 消息号实盘印证（与 `mac/commands/` 对照）

| msg_id | 命令 | 抓包印证 |
|--------|------|---------|
| 0x122B | symbol_quotes | ✓ 指数轮询（178B→570B）+ 自选股批量（418B→3114B，16 只 × ~195B） |
| 0x122A | symbol_info | ✓ 52B→332B |
| 0x122E | symbol_bar | ✓ 见第二节独立验证 |
| 0x122C | board_members_quotes | ✓ 盘中观察单股 55B→5138B（ viewed 股的板块成分报价） |
| 0x1215/0x1217 | file_query | ✓ 见第四节，F10 HTML 经此通道分发 |
| 0x123D | symbol_auction（集合竞价） | ✓ 盘中轮询（54B→2420B），内容为 `[u16][f32]` 键值对 |

## 二、symbol_bar (0x122E) 独立验证 ✅

**验证方法**：不解析源码，纯抓包解码 700 根日 K（600519），再用**量价一致性**
自校验——`成交额字段 ÷ 成交量字段` 应等于当日均价（VWAP ≈ close）。

实盘请求体（日线，与 `SymbolBarCmd.build_request` 的 `<H22sHH I HH bbb bH4s` 对齐）：
```
2e12 0100 "600519"+10×00 | 0400(周期=4日线) 0100 00000000 bc020000(700根) ...
```
周期字段实盘三元组：`03=60分钟 / 04=日线 / 05=周线`（与 `Period` 枚举一致），
由终端切换周期时的字节差分直接确认。

响应 bar（36B，起始偏移 33，与实现一致）：

| 偏移 | 实现（`<II7f`） | 独立验证 |
|------|----------------|---------|
| 0 | ymd (I) | ✓ 20231130→20261023 共 700 根严格递增 |
| 4 | time_num (I) | ✓ 日线恒 0（实现标注"盘中为秒数"合理） |
| 8/12/16/20 | open/high/low/close (f) | ✓ |
| 24 | **amount (f)** | ✓ **量价校验**：5 根抽样 amount/vol 与 close 偏差 0.2%~1.6%（即 VWAP） |
| 28 | vol (f, 股) | ✓ 茅台日成交 213~577 万股量级 |
| 32 | float_shares (f) | ✓ 恒 125619.78（茅台 12.56 亿股全流通；本文档此前的"总股本"猜读被实现标签纠正） |

> 实现注记：实现里 amount/vol/float_shares 的字段语义标签（尤其 float_shares）
> 经本次独立抓包+量价校验确认无误。双向独立路径（实盘字节 vs 源码实现）互证。

## 三、0x1215/0x1217 文件通道的实盘样本（iwshop / F10 分发）

F10 云端 HTML 经文件通道分发（`get_file_meta`/`download_file` 同族）：

- stat（0x1215）：请求 `1512 00000000 "iwshop/1_600519.htm"+pad` → 响应
  `[u32 0][u32 文件大小=42665][ASCII 摘要]`；路径前缀 `1`=沪 `0`=深
- read（0x1217）：请求 `[0x1217][u16 市场][u32 offset][u32 length][路径+pad]` →
  响应 `[u32 1][u32 length][原始字节]`；实测 30000+12665 两块取回完整页面，
  字节数与 stat 精确吻合

## 四、新数据面：F10 云端 HTTP 页面图谱（协议栈之外的补充发现）

MAC 协议之外，终端的 F10 标签页由内嵌 WebKit 加载**明文 HTTP 页面**（经终端
WebKit 网络缓存记录逆向发现）：

```
http://static.tdx.com.cn:7615/site/tdxf10/gg_<栏目缩写>/{code}.html
```

- 栏目：`gg_gsgk` 公司概况 / `gg_gdyj` 股东研究 / `gg_jyds` 龙虎榜(交易对手) /
  `gg_cwfx` 财务分析 / `gg_fhrz` 分红融资 / `gg_zlcc` 主力持仓 / `gg_zbyz` 指标业绩 等
- 数据以 `window['tql.CWServ.tdxf10_gg_<栏目>_<code>_<子集>'] = "<转义JSON>"` 内嵌
  （双引号外壳 + `\"` 转义，json.loads 前需 replace）；无反爬，nginx 直出
- 样本量：jyds 13 个数据集（龙虎榜日期/营业部明细/大宗/两融/资金流向 20 日/
  涨跌停分析…）、gdyj 的 `sdgdbgq` 十大股东 18 期×10 席（含机构类别列）
- 已在下游项目按此实现 4 个采集器，并与东财源双源对数逐笔一致

> 注意与文件通道的关系：jyds/gsgk/gdyj 三类页面同时存在于 7709 文件通道
> （iwshop 路径）与 7615 HTTP 两种分发形态；`gg_fhrz` 等其余标签页为纯壳
> 页面（数据 JS 动态拉取），不适合内嵌解析。
